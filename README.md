# Homebrew tap

Install [ai-playbook](https://github.com/Vadimkomis/ai-playbook):

```sh
brew install vadimkomis/tap/ai-playbook
ai-playbook --target "/path/to/your-project"
ai-playbook doctor --target "/path/to/your-project"
```

The package is pinned to a source revision and SHA-256. Homebrew manages Node.js. The formula is maintained in the
ai-playbook repository and copied here after testing and independent review.

Update with `brew update` and `brew upgrade ai-playbook`.
Uninstall the tool with `brew uninstall ai-playbook`; project docs are preserved.
